# LyricsFlow downloads

Synced lyrics overlay for Windows and Android. This repository only hosts the downloads (Windows installer and Android APK).

**[Download the latest version](../../releases/latest)** and run `LyricsFlow-Setup-<version>.exe`.

- Windows may show a SmartScreen warning because the app is not code-signed yet: click "More info", then "Run anyway".
- After the first install, LyricsFlow updates itself: it shows an alert when a new version is out and installs it with one click.
- Installers are checked against a SHA-256 fingerprint before they are run.
